# Fire Fight - Enhanced Windows 11 fix
A patch for the game "Fire Fight" by "Chaos Works" from 1996, to help it run on Windows 11 64bit.

You can find my newest release here: https://github.com/kasperfm/FireFight-Win11Fix

#### This patch requires the retail version of the game!


## Features:
- Fix the errors that prevent the game from starting on modern Windows.
- Enable the CD music (ripped from the original game CD).
- Updated graphics and sound DLLs.


## How to use:
1. Download my package from this GitHub page.
2. Unpack the contents into your FireFight directory.
3. Run the .bat file "PATCHFF.bat" from the game directory.
4. Now just start the game with "FIREFIGHT_PATCHED.EXE".


(I developed the patch against v1.0.0.1 of the game from my retail CD. So the game without any official patches installed.)
